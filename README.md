## 서비스 소개

2026년 6월, 한국은 체코전 2-1 승리로 대회를 시작했지만 멕시코와 남아공에 연달아 0-1로 패하며 조 3위로 탈락했습니다. 특히 최종전이었던 남아공전은 **비기기만 해도 32강에 진출**하는 경기였습니다. 후반 18분 실점 이후 한국은 밀집 수비를 끝내 뚫지 못했습니다.

REMATCH는 그 순간의 벤치에 사용자를 앉힙니다. 정적인 전술 보드가 아니라, 시간이 흐르는 경기 위에서 포메이션·선수 배치·수비 라인·압박 강도·교체를 실시간으로 조정하며 결과를 바꾸는 것이 목표입니다.

### 시나리오

| 시나리오 | 상황 | 목표 | 난이도 |
|---|---|---|---|
| 남아공전 (6/25 몬테레이) | 후반 18분 실점 직후(60분)부터 지휘 | 무승부 이상이면 32강 진출 | ★★★ |
| 멕시코전 (6/19 과달라하라) | 풀매치 90분 설계 | 승리 시 조 1위 | ★★★★ |

### 주요 기능

- **선수 자유 배치** — 경기장 위 어디로든 드래그. 놓인 위치에 따라 역할(LB / LWB / LM / LW 등)이 실시간으로 재판정되고, 판정된 역할의 라인 가중치가 팀 전력 계산에 반영됩니다.
- **포메이션 프리셋 5종** — 3-4-2-1 / 4-3-3 / 4-4-2 / 3-4-3 / 5-4-1. 경기 중에도 전환 가능(재정비 리스크 있음).
- **실시간 전술 개입** — 수비 라인·압박 강도 슬라이더, 교체 3회, 배속/일시정지.
- **상대 AI 대응** — 스코어 상황에 따라 상대가 공세(4-3-3) 또는 잠그기(5-4-1)로 전환하며, 경기장 위 상대 선수 도트가 실시간으로 이동해 시각화됩니다.
- **결과 리포트** — 실제 역사와 사용자의 결과를 나란히 비교하고 재도전을 유도합니다.

## 실행 방법

### 1. 바로 플레이 (권장)

배포 URL에 접속하면 됩니다. 별도 설치·회원가입·결제·API 키가 필요하지 않습니다.

### 2. 로컬에서 실행

```bash
git clone https://github.com/w00ye01/rematch.git
cd rematch
```

`index.html`을 브라우저로 열면 바로 실행됩니다. 빌드 과정이나 서버가 필요 없습니다.

```bash
# macOS
open index.html
# Windows
start index.html
```

### 3. 밸런싱 검증 스크립트 실행 (선택)

시뮬레이션 엔진의 난이도 균형을 자동으로 측정합니다. Node.js가 필요합니다.

```bash
node balance_test.js
```

시나리오 × 전술 조합별로 1,000경기씩 시뮬레이션해 성공률을 출력합니다. 이 스크립트는 `index.html`에 인라인된 실제 게임 엔진을 그대로 불러와 실행하므로, 배포된 서비스와 동일한 로직을 검증합니다.

**측정 결과 (각 1,000경기)**

| 시나리오 (목표) | 개입 없음 | 적극 개입 (라인↑ 압박↑ + 교체) |
|---|---|---|
| 남아공전 (무승부 이상 = 진출) | 진출 32.5% | 진출 47.7% |
| 멕시코전 (승리 = 조 1위) | 승리 18.0% | 승리 28.1% |

플레이어의 판단이 결과 확률을 유의미하게 바꾸되, 승리가 보장되지는 않는 지점으로 튜닝했습니다. 경기당 평균 총득점은 약 1.8~3.0골입니다.

## 사용 기술

| 구분 | 내용 |
|---|---|
| 프론트엔드 | 순수 HTML / CSS / JavaScript (ES6+) — 프레임워크 없음 |
| 렌더링 | SVG(경기장) + DOM 요소, CSS transition 기반 애니메이션 |
| 인터랙션 | Pointer Events API (마우스·터치 통합 드래그) |
| 시뮬레이션 | 자체 구현 규칙 기반 확률 엔진 (틱 = 경기 1분) |
| 폰트 | Pretendard (오픈 라이선스) |
| 배포 | GitHub Pages (정적 호스팅) |
| 검증 | Node.js 기반 몬테카를로 시뮬레이션 스크립트 |
| 개발 도구 | 바이브 코딩 (Claude) — 기획, 구현, 밸런싱, 문서화 전 과정 |

외부 API·서버·데이터베이스를 사용하지 않는 순수 클라이언트 사이드 구현입니다.

## 시뮬레이션 엔진 개요

경기 1분을 1틱으로 두고 매 틱마다 다음을 계산합니다.

1. **팀 전력 산출** — 선수의 현재 위치로 판정된 역할의 라인별 가중치(공격/중원/수비)로 능력치를 합산하고, 체력 계수와 전술 슬라이더 보정을 적용합니다.
2. **이벤트 판정** — 양 팀 전력비와 모멘텀으로 공격 발생 확률을 산출하고, 찬스 → 슈팅 → 유효 슈팅 → 골의 단계별 확률로 전환합니다.
3. **상대 AI** — 후반 70분 이후 스코어에 따라 공세 또는 잠그기로 전환합니다.
4. **모멘텀·체력** — 이벤트 결과가 모멘텀에 누적되고, 압박 강도와 수비 라인 높이에 비례해 체력이 소모되어 교체 타이밍이 전략 요소가 됩니다.

수비 라인을 올리면 공격력이 오르는 대신 수비력이 떨어지고 체력 소모가 빨라지도록 설계해, 극단적인 설정이 항상 유리하지는 않도록 균형을 맞췄습니다.

## 데이터에 대하여

대회 규정에 따라 팀·선수 데이터는 자체 제작했습니다. 2026 월드컵 대한민국 대표팀 명단을 참고해 25인 스쿼드를 구성했으며, 각 선수의 공격·수비·패스·스피드·체력 5개 지표와 상대팀 전력 지표는 모두 창작값입니다.

실명은 몰입감을 위해 사용했으며, 능력치와 시뮬레이션 결과는 실존 인물·팀·국가에 대한 평가가 아닙니다. 특정 선수·팀·국가를 비하하거나 명예를 훼손하는 표현은 포함하지 않았습니다.

폰트(Pretendard)는 오픈 라이선스를 확인하고 사용했습니다.
